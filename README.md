# 🛒 FastPDV

Sistema de Ponto de Venda (PDV) desenvolvido em Python e SQLite. 

## 🚀 Funcionalidades

* Cadastro de clientes
* Cadastro de produtos
* Registro de vendas
* Controle de estoque
* Persistência de dados com SQLite

## 🛠 Tecnologias Utilizadas

* Python 3
* SQLite3
